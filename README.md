## Tujuan Repositori

## Daftar dan Fungsi Berkas
- `latihan/01_biodata.py`: Program untuk menampilkan biodata mahasiswa.
- `latihan/02_persegi_panjang.py`: Program untuk menghitung luas dan keliling persegi panjang.
- `latihan/03_konversi_suhu.py`: Program untuk mengonversi suhu dari Celcius ke Fahrenheit, Kelvin, dan Reamur.
- `latihan/04_nilai_akhir.py`: Program untuk menghitung nilai akhir berdasarkan bobot tugas, UTS, dan UAS.
- `tugas/kalkulator_koordinat.py`: Program utama untuk menghitung jarak antara dua titik koordinat (x1, y1) dan (x2, y2).
- `Kuis_1_2225250209.docx`: Berkas jawaban kuis teori/soal.
- `.gitignore`: Berkas untuk mengabaikan berkas yang tidak perlu di-push ke repository.
